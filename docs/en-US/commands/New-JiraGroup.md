# New-JiraGroup

## SYNOPSIS

Creates a new group in JIRA

## SYNTAX

```powershell
New-JiraGroup [-GroupName] <string[]> [[-Connection] <AtlassianPS.Connection>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

This function creates a new group in JIRA.

## EXAMPLES

### EXAMPLE 1

```powershell
New-JiraGroup -GroupName testGroup
```

This example creates a new JIRA group named testGroup.

## NOTES

This function uses the selected Jira connection unless you pass another connection through `-Connection`.
Use `Connect-Jira` to create a connection.
For anonymous access, create the connection with `Connect-Jira -Anonymous`.

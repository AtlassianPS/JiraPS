# Remove-JiraIssueAttachment

## SYNOPSIS

Removes an attachment from a Jira issue.

## SYNTAX

### byId (Default)

```powershell
Remove-JiraIssueAttachment -AttachmentId <Int32[]> [-Credential <PSCredential>] [-Force] [-Connection <AtlassianPS.Connection>] [-ConnectionName <String>] [-Uri <Uri>] [-EmailAddress <String>] [-ApiToken <Object>] [-PersonalAccessToken <Object>] [-Anonymous] [<CommonParameters>]
```

### byIssue

```powershell
Remove-JiraIssueAttachment -Issue <AtlassianPS.JiraPS.Issue> [-FileName <String[]>] [-Credential <PSCredential>] [-Force] [-Connection <AtlassianPS.Connection>] [-ConnectionName <String>] [-Uri <Uri>] [-EmailAddress <String>] [-ApiToken <Object>] [-PersonalAccessToken <Object>] [-Anonymous] [<CommonParameters>]
```

## DESCRIPTION

This function removes an attachment from a Jira issue.

## EXAMPLES

### Example 1

```powershell
Remove-JiraIssueAttachment -AttachmentId 10039
```

Removes attachment with ID of 10039

### Example 2

```powershell
Get-JiraIssueAttachment -Issue FOO-1234 | Remove-JiraIssueAttachment
```

Removes all attachments from issue FOO-1234

### Example 3

```powershell
Remove-JiraIssueAttachment -Issue FOO-1234 -FileName '*.png' -force
```

Removes all *.png attachments from issue FOO-1234 without prompting for confirmation

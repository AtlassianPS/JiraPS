# Set-JiraFilter

## SYNOPSIS

Make changes to an existing filter.

## SYNTAX

```
Set-JiraFilter [-Filter] <AtlassianPS.JiraPS.Filter> [[-Name] <string>] [[-Description] <string>] [[-JQL] <string>]
 [[-Favorite] <bool>] [[-Connection] <AtlassianPS.Connection>] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Updates only the supplied filter properties.
PassThru returns the typed successful update response without an extra lookup.

## EXAMPLES

### Example 1

```powershell
Set-JiraFilter -Filter 12345 -Name 'Release review'
```

Update a filter without returning a record.

### Example 2

```powershell
Set-JiraFilter -Filter 12345 -Description '' -PassThru
```

Clear the description and return the successful update response.

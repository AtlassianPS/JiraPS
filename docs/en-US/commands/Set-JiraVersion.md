# Set-JiraVersion

## SYNOPSIS

Modifies an existing version in Jira.

## SYNTAX

```powershell
Set-JiraVersion -Version <AtlassianPS.JiraPS.Version[]> [-Name <String>] [-Description <String>] [-Archived <Boolean>] [-Released <Boolean>] [-ReleaseDate <DateTime>] [-StartDate <DateTime>] [-Project <AtlassianPS.JiraPS.Project>] [-Credential <PSCredential>] [-Connection <AtlassianPS.Connection>] [-ConnectionName <String>] [-Uri <Uri>] [-EmailAddress <String>] [-ApiToken <Object>] [-PersonalAccessToken <Object>] [-Anonymous] [<CommonParameters>]
```

## DESCRIPTION

This function modifies the version for an existing project in Jira.

## EXAMPLES

### Example 1

```powershell
Get-JiraVersion -Project $Project -Name 'Old-Name' | Set-JiraVersion -Name 'New-Name'
```

Changes the existing version's name to New-Name.

### Example 2

```powershell
Get-JiraVersion -Id 162401 | Set-JiraVersion -Description 'Descriptive string'
```

Changes the description of version 162401.

## NOTES

This function requires either the `-Credential` parameter to be passed or a persistent Jira session.
See `New-JiraSession` for more details.
If neither are supplied, this function will run with anonymous access to Jira.
